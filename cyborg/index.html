Cyborg Challenge.

A browser puzzle game inspired by Chip’s Challenge. The keyboard input behaves like the original Windows 3.1 game.

Your browser needs canvas support to play this game.

Press and hold to move.

Controls

  • ← ↑ ↓ → Move
  • R Restart the current level
  • P Enter a level password

Use a keyboard, or the on-screen arrows on a phone or tablet.
